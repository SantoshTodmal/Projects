## Project Overview :
- This project predicts whether a telecom customer is likely to leave the company (churn) using machine learning model.

## Dataset :
- Dataset : IBM Telco Customer Churn
- Rows: 7,043
- Features: Customer demographics, services, contract details, tenure, and charges
- Target: Churn (Yes/No)

## Technologies Used :
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- Jupyter Notebook
- Joblib
- Machine Learning Models
- Logistic Regression
- Random Forest Classifier

## Project Workflow :
- Data loading and understanding
- Exploratory data analysis (EDA)
- Data cleaning and preprocessing
- Train-test split
- Feature encoding and scaling
- Model training and evaluation
- Model comparison
- Saving the trained model
- Predicting churn for a new customer

## Conclusion :
- This project uses machine learning to predict customer churn and identify customers who are likely to leave the company.
- It helps businesses understand customer behavior and take steps to improve customer retention.
