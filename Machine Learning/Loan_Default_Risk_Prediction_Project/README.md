## About
- This folder contains my Machine Learning projects developed as part of my Data Analytics and Machine Learning learning journey.
- I use Python and popular Machine Learning libraries to analyze data, build predictive models, and evaluate model performance.

## Project Name : Loan Default Risk Prediction

- Domain: Finance
- Objective: Analyze loan applicant information and predict the risk of loan default.
- Dataset: 100,000 loan applicant records.

## Key Activities:

- Data cleaning and exploratory data analysis (EDA)
- Data visualization and feature analysis
- Classification to predict loan default risk
- Regression to estimate numerical outcomes
- Clustering to group applicants based on similarities
- Model evaluation and saving trained models

## Tools & Technologies:

- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- Joblib
- Jupyter Notebook
