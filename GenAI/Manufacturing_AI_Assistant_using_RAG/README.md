## Project Overview :
- This project uses Generative AI and Retrieval-Augmented Generation (RAG) to answer questions based on manufacturing SOP documents.
- It helps users quickly find information about manufacturing processes, maintenance, quality inspection, material handling, and safety.

## Technologies Used :
- Python
- Jupyter Notebook
- Sentence Transformers
- FAISS
- Google Gemini API
- NumPy

## Project Workflow :
- Load manufacturing SOP documents.
- Split documents into text chunks.
- Generate text embeddings.
- Store embeddings in FAISS.
- Retrieve relevant information based on user questions.
- Generate answers using Gemini AI.

## Documents Included :
- Cleaning and Sanitation
- Line Clearance
- Machine Setup
- Maintenance Guide
- Material Handling
- Quality Inspection
- Safety Compliance

## Example Questions :
- What are the common warning signs of machine problems?
- What safety precautions should workers follow?
- How should incoming materials be handled?
- What checks are required during quality inspection?
- What should workers do before changing a production line?

## Conclusion :
- This project provides a convenient way to access manufacturing procedures and operational guidelines.
- It helps users find relevant information about machine maintenance, quality inspection, material handling, and workplace safety, supporting better information access and day-to-day manufacturing operations.
