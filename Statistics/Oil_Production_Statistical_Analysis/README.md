## Project Overview :
- This project applies statistical methods to analyze oil production data and understand patterns, variations, and relationships across countries, products, and years.

## Statistical Concepts Used :
- Descriptive Statistics: Mean, median, standard deviation, minimum, and maximum.
- Measures of Central Tendency: Understanding the typical values in a dataset using mean and median.
- Measures of Dispersion: Examining data variability using variance, standard deviation, and range.
- Quartiles and Percentiles: Understanding the distribution of data values.
- Interquartile Range (IQR): Identifying observations outside the expected range.
- Distribution Analysis: Examining how values are spread across the dataset.
- Correlation Analysis: Measuring the strength and direction of the linear relationship between numerical variables.
- Trend Analysis: Examining changes in aggregate values over time.
- Percentage Change: Measuring the relative increase or decrease between years.
- Comparative Analysis: Comparing statistical results across products, countries, and flow categories.

## Tools & Technologies Used :
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## Key Statistical Findings :
- Total Oil Products recorded the highest aggregate value among the listed products.
- The United States recorded the highest average value among the countries analyzed.
- The aggregate yearly values were approximately 11.94 million in 2021, 1.52 million in 2022, and 1.51 million in 2023.
- The IQR method identified 308 observations outside the calculated limits.
- The correlation between year and value was approximately -0.115, indicating a weak negative linear relationship in the dataset.
- Standard deviation and range help assess variability.

## Conclusion :
This project demonstrates the practical application of descriptive statistics, measures of dispersion, outlier detection, correlation, and trend analysis. 
It helps develop the ability to interpret numerical data and communicate statistical findings clearly.
